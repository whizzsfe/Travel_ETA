deltaBadge()

trip.php : 83

Render a Bootstrap badge showing how early or late an arrival is.

deltaBadge(array<string|int, mixed> $search, int|null $deltaSec[, bool $isIteration = false ]) : string

Colour coding:

  • Green : 0–15 min early (ideal window)
  • Teal : more than 15 min early
  • Orange : least-late slot when a warning flag is set
  • Red : late arrival
Parameters
$search : array<string|int, mixed>

The search or iteration row from the database.

$deltaSec : int|null

Signed seconds: negative = early, positive = late, null = unknown.

$isIteration : bool = false

True when rendering an individual iteration row rather than the search summary.

Return values
string —

HTML badge element.

Render a traffic-freshness alert banner based on how far away the best departure is.

freshnessBanner(array<string|int, mixed>|null $search) : string
  • Returns an empty string if there is no completed search.
  • Returns an empty string if the best departure has already passed.

  • Beyond 2 hours: orange warning to re-run closer to departure.
